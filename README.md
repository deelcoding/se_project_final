# Final Project | TripleTen

This is the final project for the TripleTen Bootcamp. In this project, we are using a news article API to gather articles based on the content that is being searched.

This is just the front-end portion of the project, but does have a section of the code that can be uncommented to simulate a user signed in.

The languages being used are HTML, CSS, JavaScript, and React.
